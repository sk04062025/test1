Using skopeo (CLI-based)
If you prefer the command line or have hundreds of repositories and want to automate the logic via script, Skopeo is the best tool. Unlike Docker, Skopeo does not require a local daemon and doesn't need to "pull" the image to disk—it copies layers directly between registries.

skopeo copy --all \
  docker://docker.io/your-org/image:tag \
  docker://harbor.yourdomain.com/your-project/image:tag


#for login to docker repositories using skopeo

skopeo login docker.io -u your_user -p your_PAT
skopeo login harbor.domain.com -u harbor_user -p harbor_pw --tls-verify=false
# Then run the copy command WITHOUT the --creds flags

# to list tags for docker image
skopeo list-tags --creds "your_docker_user:your_PAT" docker://docker.io/your_org/your_repo


# Pro-Tip: Handling SSL
If your Harbor VM uses a self-signed certificate or a private CA that isn't in your system's trust store, you might get a "certificate signed by unknown authority" error. In that case, simply add the following flag to the skopeo copy command:
--dest-tls-verify=false

# Requirements
jq: Used to parse the JSON output of the tag list. (Install via sudo apt install jq or yum install jq).
Skopeo Login: Ensure you have run skopeo login docker.io and skopeo login harbor.domain.com before running the script.



To handle multiple images at once, the script will now read a text file where each line follows the format dockerhub_org/repo;harbor_project;harbor_image_name.
1. Create your image list (images.txt)
Create a file (e.g., images.txt) and list the images you want to migrate:
myorg/api-service;prod-apps;backend-api
myorg/frontend;prod-apps;web-ui
myorg/database;shared-services;postgres-custom

2. The Updated Migration Script (bulk_migrate.sh)

#!/bin/bash

# --- CONFIGURATION ---
HARBOR_DOMAIN="harbor.domain.com" 
VERIFY_TLS="false" 

# --- USAGE CHECK ---
usage() {
    echo "Usage: $0 <input_file>"
    echo "Format: dockerhub_image;harbor_project;harbor_image"
    exit 1
}

if [ "$#" -ne 1 ]; then usage; fi

INPUT_FILE=$1
if [ ! -f "$INPUT_FILE" ]; then
    echo "Error: File '$INPUT_FILE' not found."
    exit 1
fi

# Check for jq
if ! command -v jq &> /dev/null; then
    echo "Error: 'jq' is not installed."
    exit 1
fi

# --- START PROCESSING ---

# Read the file line by line
while IFS=';' read -r col1 col2 col3 || [ -n "$col1" ]; do
    
    # 1. Clean the inputs (remove carriage returns and extra spaces)
    SOURCE_IMAGE=$(echo "$col1" | tr -d '\r' | xargs)
    HARBOR_PROJECT=$(echo "$col2" | tr -d '\r' | xargs)
    DEST_NAME=$(echo "$col3" | tr -d '\r' | xargs)

    # 2. Skip empty lines or comment lines (starting with #)
    case "$SOURCE_IMAGE" in
        "" | \#*) 
            continue 
            ;;
    esac

    # 3. Validate that we have all three parts
    if [ -z "$HARBOR_PROJECT" ] || [ -z "$DEST_NAME" ]; then
        echo "[ERROR] Invalid line format: $col1;$col2;$col3"
        continue
    fi

    echo "========================================================"
    echo "PROCESSING: $SOURCE_IMAGE"
    echo "TARGET:     $HARBOR_DOMAIN/$HARBOR_PROJECT/$DEST_NAME"
    echo "========================================================"

    # 4. Fetch tags
    TAG_LIST=$(skopeo list-tags docker://docker.io/$SOURCE_IMAGE 2>/dev/null)
    if [ $? -ne 0 ]; then
        echo "[SKIP] Could not fetch tags for $SOURCE_IMAGE. Check login/repo name."
        continue
    fi

    TAGS=$(echo "$TAG_LIST" | jq -r '.Tags[]')
    if [ -z "$TAGS" ] || [ "$TAGS" == "null" ]; then
        echo "[SKIP] No tags found for $SOURCE_IMAGE."
        continue
    fi

    # 5. Copy tags
    for TAG in $TAGS; do
        echo "  --> Copying Tag: $TAG"
        
        skopeo copy --all \
            --dest-tls-verify=$VERIFY_TLS \
            docker://docker.io/$SOURCE_IMAGE:$TAG \
            docker://$HARBOR_DOMAIN/$HARBOR_PROJECT/$DEST_NAME:$TAG

        if [ $? -eq 0 ]; then
            echo "      [OK] Finished $TAG"
        else
            echo "      [FAIL] Failed to copy $TAG"
        fi
    done
    echo ""

done < "$INPUT_FILE"

echo "Migration Complete."
#########################################################################################

How to use it:

1. Prepare your file: Create images.txt with your semicolon-separated values.
2. Make script executable:

chmod +x bulk_migrate.sh

3. Login to both registries:

skopeo login docker.io -u <user> -p <PAT>
skopeo login harbor.domain.com -u <user> -p <pw>

4. Run the script:

./bulk_migrate.sh images.txt

Key Improvements in this version:

Dual-Loop Logic: It reads the file (outer loop) and then iterates through all tags for each image (inner loop).
Cleanup: The tr -d '\r' and xargs commands ensure that if you edited the text file on Windows or accidentally left a space after a semicolon, the script won't break.
Error Tolerance: If one repository in your list fails (e.g., misspelled name), the script will print a "SKIP" message and move on to the next image in your list rather than crashing.
Comments Support: You can now add comments in your images.txt file using # at the start of a line.
